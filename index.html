The two-year plan

Run your Animation program from one app

Everything a teacher needs to run a CTE Animation program — on any device, no setup. This first screen is the two-year plan: what students do each year, the Yavapai College course it earns, and every video. The other tabs fill in next.

Three things run in every class, all year:
Hands-onThe craft. DocsAnimation videos + iPad work. Watch on the Chromebook (headphones), make it on the iPad.
CollegeThe credit. Each semester's work genuinely matches its Yavapai course — real credit, and a stipend for you.
StandardsThe test. The Animation prep app runs as its own weekly track toward the CTE certification.
Always-onDaily habit. Pencil tests and sketchbook run continuously — this is an animation program first.
Two levels, four college courses, no wasted class. The Yavapai dual-enrollment is a two-year program: Animation I earns two courses, Animation II earns the other two — all four, the maximum. A third level would add no credit, so we don't run one. Naming your second-year class "II" also lands the credit correctly (the catalog pins it to "Digital Animation II"). Stipend is per course (~$750 historically — confirm the current figure with Rich Dambrov).
